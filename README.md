# PhonePe Payments Dashboard

A responsive, PhonePe-inspired payments dashboard built with standalone Angular components and strict TypeScript. This portfolio project uses sample data; payment actions are illustrative and do not move money.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200` if it does not open automatically.

## Highlights

- Responsive dashboard with a desktop sidebar and compact mobile layout
- Transaction search and category filters
- Balance visibility toggle
- Interactive payment action dialogs and status toasts
- Monthly spending visualization, linked accounts, and security status
- Accessible labels, visible keyboard focus, and reduced-motion support

## Stack

Angular 19 · TypeScript strict mode · CSS · Google Fonts

## Project structure

- `src/app/app.component.ts` — dashboard state, sample data, and interactions
- `src/app/app.component.html` — semantic Angular template
- `src/styles.css` — responsive visual system
